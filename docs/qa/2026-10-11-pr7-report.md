## 鍵盤

標題上唯一可聚焦的控制是 `title-start`（`tabIndex` 0）。載入後 `document.activeElement` 就是它。`outline` 是 `rgb(255, 241, 201) solid 3px`，`outline-offset` 5px，鍵盤聚焦看得到。

Tab 四次的焦點是：body → 按鈕 → body → 按鈕。沒有藏起來的輸入框，也沒有焦點陷阱。沒先用滑鼠點，直接按 Enter（約 1.3 秒，含點燈）和 Space 都會進到街道，主角是小白。

## prefers-reduced-motion

`reducedMotion: 'reduce'` 時 `matchMedia` 為真。點按鈕到街道 **198 ms**。一般動效是 **1,345 ms**（`titleLightMs` 1,200，再加一點點繪製）。CSS 在 `prefers-reduced-motion: reduce` 把點燈 animation 關掉，JS 用 `TITLE_REDUCED_MOTION_MS`（80）收尾。遊戲有開始。

## 字級意見

Gemu 說按鈕字偏小、標題偏大。量到的比例支持這件事。標題不是字，是一張寬圖：`.title-logo-wrap` 的寬是 `min(82%, 1040px)`，高隨圖的 330/1212。按鈕字是 `clamp(1.7rem, 2.7vw, 2.55rem)`。1080p 上標題高 283px、按鈕字 40.8px，大約 **6.9 倍**。1280×500 上標題高 283px，佔掉視窗的 57%，對按鈕字 34.6px 是 **8.2 倍**。390×844 標題只有 87px，這個抱怨主要出在橫向和矮畫面。

按鈕字在 1080p 和 2560 都頂到 2.55rem（40.8px），木牌卻有 420×99，字只佔牌高的四成，所以看起來小。不是 viewport 沒把 `vw` 放大，是上限太低，再加上 `letter-spacing: 0.14em` 和左右各 72px 的 padding。

建議（只改 CSS，不用改圖）：

```css
.title-logo-wrap {
  width: min(72%, 760px);
}
.title-logo {
  max-height: 20vh;
  object-fit: contain;
}
.title-start {
  font-size: clamp(1.9rem, 3.2vw, 3.15rem);
  letter-spacing: 0.08em;
}
```

| Viewport | 現在按鈕 | 建議按鈕 | 現在 Logo 高 | 建議 Logo 高 |
|---|---|---|---|---|
| 1920×1080 | 40.8px | 50.4px | 283px | 207px |
| 1280×800 | 34.6px | 41.0px | 283px | 160px |
| 1366×768 | 36.9px | 43.7px | 283px | 154px |
| 2560×1080 | 40.8px | 50.4px | 283px | 207px |
| 1920×600 | 40.8px | 50.4px | 283px | 120px |
| 1280×500 | 34.6px | 41.0px | 283px | 100px |
| 390×844 | 27.2px | 30.4px | 87px | 76px |

50px 的四個字加 0.08em 字距，放進 420px 寬的牌（扣掉 padding 之後內容區大約 268px）還夠。390px 的下限 1.9rem（30.4px）在 78% 寬的牌裡也放得下。矮畫面把 Logo 收到 20vh，狗上方的空位會回來。
