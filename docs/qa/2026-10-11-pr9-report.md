- 回填只收「這個攤、這個等級賣得了」的商品。刨冰改成 Lv.1 再遷移，商品只剩香草。一般中盤檔沒有多標。
- 打造的洞還在，不擋合併：v3 的 `seenProducts` 會和回填取聯集，手寫 `skewer-meteor` 或目錄裡沒有的 id 會留著。把一番賞格子從 JSON 拿掉再以 schema 3 匯入，下一個時段會再免費放回一座，不退錢、也不會同時有兩座。
