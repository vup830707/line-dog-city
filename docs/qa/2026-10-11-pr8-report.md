# QA：PR #8 手機選單與卡片建造

HEAD 核對過：`origin/cursor/phone-build-menu-e737` 是 `374663e725d58477e42522f304f826f603c7fbe2`。它的 parent 是 `fc79642`。現在的 `main` 是 `cf820c0`（已含 PR #7 全螢幕標題）。這支 PR 比 `main` 少了標題畫面那一個 commit。

## 結論：不可合併

阻擋項只有一件：這支分支合不上現在的 `main`。功能本身（手機、建造、存檔、經濟）在它自己的樹上是通的，合進去之前要先 rebase，並把 e2e 從舊的選角畫面改成「開始營業」。

在 `fc79642` 上試過 `git merge --no-ff`，自動合併失敗。衝突檔：

| 檔案 | 兩邊各加了什麼 |
|---|---|
| `config.json`、`src/rules/types.ts` | main 的 `titleLightMs`，PR 的 `phoneHeightRatio` / `buildAnimMs` |
| `src/assets/assetMap.ts`、`assetMap.test.ts`、`scripts/check-pwa.mjs` | 標題圖和手機圖的路徑 |
| `e2e/new-game.spec.ts` | main 按 `title-start`／「開始營業」；PR 仍按 `dog-white`、填名字、按 `start-game` |

`e2e/phone.spec.ts` 也是舊的選角流程。rebase 之後那些測試會對不上 `cf820c0` 的標題。PR 自己的 `index.html` 標題仍是「線條小狗模擬城市」。新遊戲確認後回到的也是這個舊標題。

沒有把衝突解進 PR 分支，也沒有推 `cursor/phone-build-menu-e737`。

## 字級、點擊範圍、發光格子

手機沒有溢出 viewport。app 名稱是 **12px**，狀態列和卡片價格是 **13px**，都低於 14px。`關閉` 按鈕大約 **55×24**，高度低於 32px。

390×844 的六個 app 按鈕大約 **26×36 到 26×49**。寬度低於 32px。1280 和 1920 的 app 按鈕大約 67×72 以上，只有「關閉」偏矮。

發光用的是點卡片前後的 hitbox 差（canvas 上的金色燈籠會污染取色，所以不以取色為準）：

| Viewport | 空格 hitbox 相對原本的腳底 |
|---|---|
| 1280×720 | slot-9 上移 **52px**，slot-14 上移 **39px**，其餘空格 0 或 7px |
| 1920×1080 | 七個空格都上移 **7px** |
| 390×844 | 七個空格都左移 **20px**、上移 **7px** |

`clearOfDock()` 在格子中心掉進底部卡片列時，把可點的金框抬到 `dockTop - 48`。canvas 上的發光圈仍畫在攤位腳底。抬起來的那一格還是點得下去（slot-9 蓋燈籠成功），但金框和攤位腳底會分開幾十 px。

截圖在 `docs/qa/pr8/`。

## 試玩報告

以新玩家玩了大約 15 分鐘遊戲時間（`runTicks(900)`，再加上前面的蓋攤和改工作）。建造的路徑清楚：吊飾 → 建造 → 點卡片 → 空格發光 → 再點格子。買不起的卡片會變灰並寫還差多少，這點很好懂。

卡關：

- 開場五個攤都已經在了。新玩家第一個能蓋的多半是側邊的裝飾，不是「蓋出第一個攤」。
- 許願池和星星鎖著，要集滿 8 款。15 分鐘只到 2 / 8。
- 沒有拆除。花車一路蓋到沒錢，那些格子就拿不回來。
- 把負責補貨的狗改成招呼之後，15 分鐘只從 370 賺到 1,220。貨架空了就幾乎不進帳。員工 app 沒有提醒「現在沒人補貨」。

破圖：檢查過的 `img` 都有 `naturalWidth`。手機外框在 1280、1920、390 都在畫面裡。沒有看到裂開的圖或橫向捲軸。390 的問題是圖示太小，不是破圖。

前五個修改：

1. rebase 到 `cf820c0`，e2e 改走「開始營業」，衝突處把 `titleLightMs` 和手機欄位一起留下。
2. 390 的 app 按鈕加到至少 44px，名稱至少 14px。
3. 「關閉」加高到 32px 以上。
4. 發光圈和可點的金框用同一組座標；卡片列真的蓋住腳底時再抬。
5. 蓋錯不能拆的時候，至少在卡片上把「已經在夜市裡」放得更顯眼，並在沒人補貨時給一句提示。
