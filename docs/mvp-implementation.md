# 放置夜市 MVP 實作計畫

企劃：`docs/plan.md` v0.4，含第 10 節已核定的答案。本機 `base` 為 `/`，Pages 與 e2e 用 `/line-dog-city/`。

## 模擬

純函式放在 `src/rules/`，不碰 React。一個 tick 的順序：時段結束就換天氣與清潔度下降 → 員工依工作與等級行動 → 街上的動物往目標走並消費 → 到點的來客生成 → 一番賞空箱慢慢補貨 → 種子往前。視窗開著時 1 tick＝1 秒；離線用同一支 tick，最多 8 小時。

氣氛＝裝飾分數＋攤位外觀＋清潔度。來客係數＝`clamp(氣氛 / 40, 0.6, 1.5)`。天氣和時段只改誰出現，不把總來客打低；節日（第 15、22、30 天）略增來客。

動物 8 種，畫成色塊。滿意度夠、又碰到該種的條件（喜歡的攤＋附近裝飾）才寫信。小狐狸要節日且箱裡還有 A 或 B；雲朵熊要許願池已擺上且氣氛達標。

員工：兩隻狗加最多兩名（文鳥、雪貂）。工作是補貨、掃地、招呼，等級讓動作變快。售價固定，賣出時扣四成補貨成本，所以被動 tick 不會讓金幣變少。

一番賞：擺下攤位就解鎖。客人抽籤，造型進圖鑑，重複換幣。箱子空了或收攤退 30% 之後，過一段 tick 自動開新箱，不預扣 2,670。八款集滿才能擺流星許願池；許願 60% 改下一天天氣。

## 存檔

schema 第 3 版。第 1、2 版（舊的策略夜市）讀進來就開新遊戲。匯出／匯入仍是 JSON。

## 畫面

電腦全視窗。Canvas 2D 畫側視街道；格子上的透明區負責拖放和點選。面板：建造、員工、圖鑑、信件。`window.__puppy` 提供測試用的加速 tick 與離線回撥，正式遊玩不會自己打開。

## 刪除

對手、比價、懲罰型人潮、舊的營業 tick、每日結算，以及對應測試。PWA 與 `pages.yml` 維持只在 `main` 部署。

## 這一版不做

窄條模式、子母畫面、手機版面、港灣／櫻花／雪町、音效、成圖。
